# JediMindAgent (в разработке)

ИИ-ассистент по книге Максима Дорофеева «Путь джедая». Определяет уровень джедайской зрелости пользователя коротким тестом в чате, ведёт диалог о его состоянии и подбирает практики из книги — не выше его уровня.

## Обзор

**1. Тест уровня в чате.** Новый пользователь начинает с 11 вопросов: по одному, с кнопками вариантов. Уровень считается по баллам без участия LLM.

![Тест уровня в чате](img/level-test.png)

**2. Разговор с агентом.** Агент уточняет состояние, опирается на фрагменты книги своего уровня и показывает источники. Панель слева обновляется по ходу разговора.

![Чат с агентом и панель состояния](img/chat.png)

**3. Упражнения.** Предложенные практики пользователь оценивает: «Подходит» или «Не подходит», оценку можно поменять или удалить упражнение.

![Разделы упражнений](img/exercises.png)

## Возможности

- **Тест уровня** — 10 вопросов об уровне и вопрос о мыслетопливе. Уровень 1–5 = среднее баллов, округлённое вниз. Перетест — кнопкой в панели состояния.
- **Пять уровней из главы 6 книги** — от «Все горит» до «Естественно, спонтанно и все во благо». Уровень — потолок практик: агент не предлагает практики выше уровня пользователя.
- **Агент на OpenAI-совместимом API** со structured output: ответ, обновление метрик (мыслетопливо, фокус, главная проблема, время на практики) и одно упражнение.
- **RAG по книге** — PDF → фрагменты с разметкой уровня → локальные эмбеддинги → ChromaDB. Агент получает только фрагменты своего уровня и ниже.
- **Оценка упражнений** — «Новые / Подходят / Не подходят», удаление.
- **Память** — история чата, состояние, упражнения и попытки теста в PostgreSQL. Кнопка «Начать сначала» полностью удаляет данные.
- **Веб-интерфейс** на HTML + CSS + JS без сборки, светлая и тёмная тема.


## Стек

Python 3.12 · FastAPI · SQLAlchemy 2 (async) + Alembic · PostgreSQL 16 · LangChain `ChatOpenAI` · ChromaDB · sentence-transformers (`paraphrase-multilingual-MiniLM-L12-v2`) · pypdf · Docker Compose.

## Быстрый старт

**1. Настройте `.env`** по шаблону `.env.example`:

```env
APP_NAME=JediMindAgent
APP_ENV=local
OPENAI_API_KEY=sk-your-key
OPENAI_CHAT_MODEL=gpt-4.1-mini
OPENAI_BASE_URL=https://api.openai.com/v1
```

Для OpenAI-совместимого провайдера поменяйте `OPENAI_BASE_URL` и модель. `DATABASE_URL` для Docker задаётся в `docker-compose.yml`. Без `OPENAI_API_KEY` приложение работает, но вместо ответов агента показывает заглушку.

**2. Запустите контейнеры:**

```bash
docker compose up --build
```

Поднимутся `app` (порт 8000), `db` (PostgreSQL, с хоста — порт 15432) и `chroma`. Миграции применяются автоматически при старте. Первая сборка долгая: ставится torch для `sentence-transformers`.

**3. Загрузите книгу.** PDF кладётся в `data/sources/` — директория исключена из git и Docker build context:

```bash
docker compose exec app python -m jedi_mind_agent.rag.ingest /app/data/sources/jedi-path.pdf --source-slug jedi-path --source-title "Путь джедая" --replace
```

Первый запуск скачивает embedding-модель в volume `model_cache`; загрузка книги занимает 2–3 минуты. В конце печатается сводка, в том числе `chunks_by_level` — сколько фрагментов попало на каждый уровень. `--replace` обязателен при повторной загрузке того же источника.

**4. Откройте** `http://localhost:8000/` — тест начнётся автоматически.

Проверка работоспособности:

```bash
curl http://localhost:8000/health
```

```bash
curl http://localhost:8000/health/db
```

Остановить контейнеры (с `-v` — удалить и данные PostgreSQL, ChromaDB, кэш модели):

```bash
docker compose down
```

## API

Продуктовый API, который использует веб-интерфейс. Пользователь один, `user_id` в запросах не передаётся. Полная схема — `http://localhost:8000/docs`.

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/v1/me/state` | уровень и метрики |
| `GET` | `/api/v1/me/messages` | история чата |
| `POST` | `/api/v1/me/level-test` | `{"restart": false}` — начать или продолжить тест; `true` — пройти заново |
| `POST` | `/api/v1/chat/messages` | `{"message": "...", "use_rag": true}` — ответ на вопрос теста или сообщение агенту |
| `GET` | `/api/v1/exercises` | упражнения с допустимыми оценками в `actions` |
| `PATCH` | `/api/v1/exercises/{id}` | `{"status": "suitable" \| "not_suitable"}` |
| `DELETE` | `/api/v1/exercises/{id}` | удалить упражнение |
| `POST` | `/api/v1/me/reset` | удалить все данные пользователя |

## Ограничения

- **Один пользователь, без авторизации.** Код готов к нескольким: текущего пользователя определяет одна зависимость `get_current_user()`.
- **Примечания в конце книги размечены как общие.** Для пользователей низких уровней они иногда вытесняют полезные фрагменты из выдачи.
- **Порога релевантности в поиске нет** — в контекст всегда попадают `top_k` фрагментов.
- **Ответ агента приходит целиком**, без стриминга; обычно это 5–25 секунд.
- **Данные теста и истории отправляются в OpenAI-совместимый API**, который указан в `.env`.
